v8.15.52 TTS 낭독 파이프라인 개편 & 음성 요약 최적화
2026.08.28 Latest
브라우저 보안 정책(User Gesture)에 의한 음성 낭독 차단 문제를 원천 해결하고, 복잡한 답변을 청취용 2~3문장 핵심 요약으로 압축 전달하도록 TTS 파이프라인을 전면 개선했습니다.
음성 낭독(TTS) 엔진 안정화
  • Chrome User Gesture 보존 전략 적용: 읽기 버튼 클릭 시 원본 텍스트로 즉시 음성 출력을 개시하여 비동기 API 대기 중 발생하는 제스처 만료 차단 방지
  • 비디오 사이트 TTS 트리거 보존: YouTube, Netflix 등 성능 보호 예외 도메인에서도 우클릭 해제만 스킵하고 TTS 물리 트리거는 정상 배치되도록 개선
  • 음성 입력 자동 낭독 레이턴시 제거: 음성 질문 완료 후 즉시 낭독 스트림으로 연결되는 다이렉트 패스 구성
낭독 전용 스토리텔링 스킬 정제
  • 2~3문장 핵심 낭독 압축: 불필요한 서두·배경 설명과 나열식 표현을 배제하고 결론과 핵심 근거 위주로 청취 최적화
  • 마크다운/메타 태그 필터링: 코드 블록, HTML, 다이어그램, 인용 출처 기호를 음성 낭독에서 자동 정제
v8.15.50 모듈형 스킬(Skills) 아키텍처 도입

스킬 라우터 & 플러그인 모듈화
  • 지능형 스킬 라우터 엔진: 웹 탐색, 페이지 분석, 다이어그램 생성, 캘린더 등록, 음성 요약 인텐트를 키워드 및 대화 패턴으로 판별하여 최적 프롬프트 자동 조립
  • 기능별 독립 플러그인 체계: 기본 대화 가이드, 페이지 크롤링 분석, 실시간 웹 검색, 차트 시각화, 일정 등록, 낭독 스토리텔링 전용 모듈 분리
프롬프트 토큰 효율 및 응답 품질 향상
  • 질문 맥락에 무관한 불필요한 규칙 주입을 방지하여 응답 생성 레이턴시 단축 및 컨텍스트 낭비 최소화
  • 마크다운 정형 테이블 출력 가이드 및 헤더 구분선 검증 로직 내재화
v8.15.43 글로벌 단축키(Alt+J) 개편 & Mermaid 시각화 안정화
2026.08.26 Stable
OS 간 단축키 충돌을 방지하고, Shadow DOM 환경에서 복잡한 구조의 Mermaid 다이어그램 렌더링 실패 문제를 해결했습니다.
렌더링 엔진 결함 해결
  • Shadow DOM 임시 렌더링 샌드박스: 렌더링 컨테이너 초기화 예외를 방지하기 위한 독립 샌드박스 기반 차트 렌더링 파이프라인 구축
  • Mac 단축키 충돌 방지: 브라우저 강제 종료(Cmd+Q) 오타 위험을 방지하기 위해 기본 단축키를 Alt + J로 통합
  • 웹사이트 릴리즈 자동 배포 파이프라인: 버전 릴리즈 시 공식 웹사이트 및 가이드 페이지 자동 동기화 배포 체계 연동

왜 WithAvis일까요?

생산성을 극대화하는 8가지 혁신적인 AI 파워 기능

100% 서버리스 멀티 LLM & 모델 관리

Google Gemini, Anthropic Claude, Cerebras Llama, OpenCode Zen 등 다양한 AI 모델을 Direct Streaming으로 지원하며, 팝업에서 원하는 모델을 자유롭게 등록·관리합니다.

YouTube 자막 & 스마트 웹 크롤링

유튜브 접속 시 자막(Transcript)을 자동 추출하여 동영상 핵심을 3초 만에 요약하고, 웹페이지 노이즈를 정제하여 핵심 본문을 수집합니다.

Mermaid 차트 자동 시각화 & PNG 저장

AI 복잡한 답변을 순서도(Flowchart), 시퀀스 다이어그램으로 자동 시각화합니다. 대형 줌/팬 모달 및 고해상도 PNG 복사/저장 기능 제공.

STT 음성 질문 & Web Speech TTS 낭독

Alt+V 단축키 한 번으로 키보드 없이 마이크로 말하고, AI 답변을 고품질 한국어/영어 음성으로 자연스럽게 청취하세요.

핀(Pin) 카드 상단 고정 & 자유 리사이징

중요 답변 코드나 요약 카드를 상단에 고정해 둔 채 작업이 가능하며, 마우스 드래그로 위젯 높이와 넓이를 자유롭게 조절합니다.

우클릭 & 복사 제한 무력화

텍스트 복사 금지, 드래그 방지, 우클릭 제한이 적용된 블로그나 웹사이트의 제약을 클릭 한 번으로 손쉽게 해제합니다.

내장 Ad Cleaner (광고 제거)

웹페이지 내 불필요한 배너 광고 및 스폰서 요소를 자동 필터링하여 눈의 피로를 줄이고 쾌적한 가독성을 제공합니다.

출처 근거 하이라이팅 (Source Grounding)

AI가 요약 및 답변을 생성할 때 참조한 웹페이지 원문 텍스트 위치를 시각적으로 강조 표시하여 정보 신뢰도를 극대화합니다.

차원이 다른 브라우징 편의성

번거로운 반복 작업 없이, 웹서핑과 정보 습득 속도를 극대화합니다

기존의 번거로운 방식
  • 웹 텍스트를 긁어서 AI 탭에 매번 복사/붙여넣기
  • 30분짜리 YouTube 영상을 일일이 넘겨가며 내용 파악
  • 긴 텍스트 답변을 읽느라 한눈에 구조 파악 불가
  • 우클릭/드래그가 막힌 사이트에서 자료 수집 한계
  • 본문을 가리는 광고와 배너로 산만한 탐색 환경

API Key 발급 가이드

WithAvis는 개인 API Key를 사용하여 중계 서버 없이 최신 AI 모델과 1:1로 직접 스트리밍 통신합니다.

100% Zero-Trust 안전 보장
발급받은 API 키는 개발자나 중간 서버로 절대 전송되지 않으며, 오직 귀하의 크롬 브라우저 암호화 로컬 스토리지(chrome.storage.local)에만 안전하게 보관됩니다.

Google Gemini (추천)

Google 계정만 있으면 완전 무료로 분당 15회(RPM)까지 강력한 Gemini 2.5 모델을 사용할 수 있습니다.

Google AI Studio 바로가기
1
Google AI Studio 접속 및 로그인
Google AI Studio에 접속한 후 개인 Google 계정으로 로그인합니다.
2
[Get API key] 메뉴 선택
좌측 상단 네비게이션 메뉴에서 [Get API key] 버튼을 클릭합니다.
3
API 키 생성 ([Create API key])
[Create API key] 버튼을 클릭하고, 프로젝트 선택 창에서 "Create API key in new project" (새 프로젝트에서 키 생성)를 선택합니다.
4
API 키 복사 및 WithAvis에 등록
화면에 표시된 AIzaSy... 형태의 키를 복사한 뒤, WithAvis 확장 프로그램 팝업의 [API Key] 입력창에 붙여넣습니다.
형식: AIzaSy***********************************

WithAvis에 키를 등록하는 초간단 3단계

API 키를 복사하셨다면, 브라우저에서 단 10초 만에 설정을 완료할 수 있습니다.

STEP 01
확장 프로그램 아이콘 클릭

브라우저 우측 상단의 퍼즐/WithAvis 아이콘을 클릭하여 설정 팝업을 엽니다.

STEP 02
AI 엔진 선택 및 키 붙여넣기

원하는 AI 엔진(Gemini, Cerebras 등)을 고르고 복사한 키를 붙여넣습니다.

STEP 03
Alt + J 로 즉시 사용

어느 웹페이지에서든 Alt + J 를 누르면 AI 비서가 즉시 작동합니다!

# 🚀 Instant AI Chat Widget

> **웹페이지의 핵심을 꿰뚫어 보는 가장 똑똑한 방법.**
> 본 브라우저 익스텐션은 보고 있는 웹페이지의 컨텐츠를 AI가 실시간으로 분석하여 요약, 질의응답 및 정보 구조화를 돕는 프리미엄 스마트 비서입니다.

---

## 🌟 주요 핵심 기능

### 1. 지능형 웹 컨텐츠 분석
* **실시간 크롤링**: 현재 활성화된 탭의 텍스트와 데이터를 즉시 읽어 들여 AI 모델에게 전달합니다.
* **맥락 기반 답변**: 페이지 전체 내용을 이해한 상태에서 사용자의 질문에 가장 정확한 답변을 제공합니다.

### 2. 프리미엄 글래스모피즘 UI/UX
* **감각적인 디자인**: 투명한 유리 질감과 부드러운 애니메이션이 적용된 초현대적인 인터페이스를 제공합니다.
* **지니 이펙트(Genie Effect)**: 위젯이 호출될 때 부드럽게 튀어나오고 들어가는 고급스러운 시각 효과를 적용했습니다.

### 3. 강력한 스마트 마크다운 렌더링
* **시각적 구조화**: 복잡한 정보를 헤더(Header), 리스트(List), 테이블(Table)로 완벽하게 변환합니다.
* **차트 지원**: Mermaid 차트 엔진을 내장하여 복잡한 로직이나 단계를 시각적인 다이어그램으로 그려냅니다.
* **계층적 들여쓰기**: 소주제와 상세 설명 간의 종속 관계를 명확하게 보여주는 지능형 인덴트 시스템을 탑재했습니다.

### 4. 멀티 모델 및 대화 관리
* **최신 AI 엔진 지원**: Gemini 등 다양한 최신 AI 모델을 선택하여 사용할 수 있습니다.
* **대화 내역 보존**: 사이트별로 대화 내역을 로컬에 저장하여 나중에 다시 방문했을 때 이어갈 수 있습니다.

---

## 🛠 사용 방법

### 1. 호출 및 토글
* **단축키**: `Alt + Q`를 눌러 위젯을 즉시 열거나 닫을 수 있습니다.
* **플로팅 버튼**: 화면 우측 하단의 아이콘을 클릭하여 활성화할 수 있습니다.

### 2. 설정 관리
* **확장 프로그램 팝업**: 툴바의 아이콘을 클릭하여 API 키 설정, AI 모델 선택, 대화 내역 초기화 등을 수행할 수 있습니다.

### 3. 코드 복사
* AI가 출력한 코드 블록 우측 상단의 복사 버튼을 눌러 소스코드를 즉시 클립보드에 저장할 수 있습니다.

---

## 🛡 개인정보 보호 및 보안

* **로컬 우선 주의**: 사용자의 설정 정보와 대화 내역은 브라우저의 로컬 저장소(`chrome.storage.local`)에만 저장됩니다.
* **휘발성 서버 데이터**: 웹페이지 분석을 위해 전송되는 데이터는 답변 생성 후 즉시 폐기되며, 별도의 DB에 저장되지 않습니다.
* **심사 준수**: 크롬 웹스토어의 보안 가이드라인에 맞춰 'key' 제거 및 '난독화' 공정을 거쳐 안전하게 배포됩니다.

## 📂 프로젝트 구조

```text
chat-injector/
├── extension/          # 익스텐션 소스 코드 (개발용)
│   ├── icons/          # 고해상도 프리미엄 아이콘 세트
│   ├── background.js   # API 라우팅 및 백그라운드 로직
│   └── content/        # UI 렌더링 및 텍스트 분석 엔진
├── dist/               # 난독화 및 최적화가 완료된 배포용 폴더
├── build.js            # 자동 버전 관리 및 빌드 파이프라인
└── doc/                # 시스템 상세 설계 및 가이드 문서
```

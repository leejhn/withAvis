## ⚡ 차원이 다른 브라우징 편의성 (Why WithAvis?)

| ❌ 기존의 번거로운 방식 | ✨ **WithAvis**와 함께하는 스마트한 방식 |
| :--- | :--- |
| 웹 텍스트를 긁어서 AI 탭에 매번 복사/붙여넣기 | **웹페이지 접속 상태 그대로 `Alt + J`로 즉시 질의응답** |
| 30분짜리 YouTube 영상을 일일이 넘겨가며 내용 파악 | **영상 접속 즉시 3초 만에 자막 자동 요약 & 타임라인 분석** |
| 긴 텍스트 답변을 읽느라 한눈에 구조 파악 불가 | **AI 답변을 Mermaid 순서도/시퀀스 차트로 자동 시각화** |
| 우클릭/드래그가 막힌 사이트에서 자료 수집 한계 | **원클릭 우클릭/복사 제한 해제로 자유로운 텍스트 분석** |
| 본문을 가리는 광고와 배너로 산만한 탐색 환경 | **스마트 Ad Cleaner로 광고 없이 핵심 본문에만 집중** |

## 🌟 핵심 주요 기능 (Key Features)

### 1. 🤖 100% 서버리스 멀티 LLM & 모델 관리
중간 중계 서버가 없는 **Direct Streaming 아키텍처**로 최소 지연 시간(Low Latency)을 보장합니다.
* **Google Gemini**: Gemini 3.5 Flash Lite 등 고성능 멀티모달 모델
* **Anthropic Claude**: Claude 3.7 Sonnet 정밀 분석 및 코딩 지원
* **Cerebras Llama**: 초고속 Llama 3 인퍼런스 엔진 지원
* **커스텀 모델 관리**: 팝업에서 원하는 모델과 개인 API Key를 자유롭게 등록·관리

### 2. 🧠 지능형 웹 컨텐츠 & 문서·자막 분석
* **스마트 웹 크롤링**: 광고·노이즈를 제거하고 핵심 본문(최대 15,000자)만 정제하여 AI에 전달
* **YouTube 자막 3초 요약**: 유튜브 접속 시 영상 자막(Transcript)을 자동 수집하여 타임라인별 Q&A 지원
* **멀티모달 PDF & 이미지 분석**: Drag & Drop 또는 붙여넣기로 문서와 이미지를 AI에게 직접 전달

### 3. 📊 내장 Mermaid 다이어그램 자동 시각화
* **자동 차트 변환**: AI 답변 내 순서도(Flowchart), 시퀀스 다이어그램, 파이차트 등을 실시간 렌더링
* **인라인 줌/팬 & PNG 다운로드**: 생성된 다이어그램을 클릭해 고해상도 모달에서 확대하고 PNG 이미지로 저장

### 4. 🎙️ 음성 인식(STT) & 스토리텔링 낭독(TTS)
* **STT 음성 질문**: `Alt + V` 한 번으로 키보드 입력 없이 마이크를 통해 질문
* **TTS 음성 낭독**: 복잡한 답변을 쉬운 구어체 스토리텔링으로 재구성하여 자연스럽게 음성 안내

### 5. 📌 핀(Pin) 카드 고정 & 자유로운 UI 커스텀
* **중요 답변 핀 고정**: 핵심 요약이나 코드를 위젯 상단에 핀으로 올려두고 웹서핑 지속
* **투명도 및 크기 조절**: 작업 화면을 가리지 않도록 마우스 드래그 리사이징 및 투명도 조절 지원

### 6. 🔓 우클릭/복사 제한 해제 & 클린 뷰(Ad Cleaner)
* 우클릭 금지, 드래그 차단 사이트의 제약을 원클릭으로 해제
* 지능형 Ad Cleaner로 산만한 광고 요소를 숨기고 본문에만 집중

## 🛠️ 사용 방법 (User Guide)

### ⌨️ 편리한 단축키 & 인터랙션
| 조작 방식 | 단축키 / 동작 | 설명 |
| :--- | :--- | :--- |
| **위젯 토글** | `Alt + J` *(Mac: `Option + J`)* | 챗봇 대화 위젯 열기 / 닫기 |
| **음성 질문** | `Alt + V` *(Mac: `Option + V`)* | 마이크 음성 인식(STT) 즉시 시작 |
| **우클릭 메뉴** | 텍스트/이미지 선택 ➔ 우클릭 | 선택 영역을 AI 질문으로 즉시 전송 |
| **플로팅 버튼** | 화면 우측 하단 런처 클릭 | 챗봇 위젯 열기 |

### ⚙️ 팝업 환경설정 (브라우저 확장 프로그램 아이콘)
1. 브라우저 우측 상단 퍼즐 아이콘 ➔ **WithAvis** 클릭
2. **AI 제공자 선택**: Gemini, Claude, Cerebras 중 원하는 엔진 선택
3. **API Key 입력**: 개인 API Key 안전하게 입력 및 저장 (로컬에만 암호화 보관)
4. **옵션 토글**: 우클릭 제한 해제, 도메인별 대화 이력 보존 등 자유롭게 온/오프

## 🛡️ 개인정보 보호 & Zero-Trust 보안

1. **100% 로컬 저장소 보관**: 사용자의 API 인증 키와 대화 내역은 외부 서버로 전송되지 않으며, 브라우저 로컬 암호화 저장소(`chrome.storage.local`)에만 안전하게 보관됩니다.
2. **0% 중계 서버 로그 데이터 저장**: 개발자 또는 제3자 프록시 서버를 일체 거치지 않는 순수 클라이언트 Direct 통신 구조입니다.
3. **메모리 즉시 소멸 분석**: 웹페이지 및 첨부파일 데이터는 AI 답변 생성 직후 메모리에서 즉각 파기됩니다.
